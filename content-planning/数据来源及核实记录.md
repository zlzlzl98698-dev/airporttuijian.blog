## 一、数据来源与基准环境说明

本项目知识库中所有品牌数据、测速指标与套餐价格均来自以下可信来源，并执行双重交叉校验：

### 1. 原始资料输入文件
- `32家机场品牌清单.txt`（最后基准日期：2026-10-19）
- `光速云品牌信息.txt`（2026 年最新资费与架构资料）
- `第三方代理客户端.txt`（GitHub 与 App Store 官方仓库资料）

### 2. 基准测试环境
- **宽带接入**：中国联通 1000M FTTH 独立光纤专线
- **客户端核心**：Clash Verge Rev v1.7.x（内置 Mihomo 内核）
- **测速节点与工具**：Speedtest.net（挑选目标落地机房本地电信商锚点）
- **流媒体/AI 检测脚本**：RegionRestrictionCheck 与 OpenAI 官方 API 连通性探针

## 二、数据等级分类定义

为了保证信息透明度与 Google/Bing EEAT 标准，全站数据打上明确等级：
1. **`verified`（已验证实测数据）**：由第三方网络实验室在标准测试环境下实际测得，具备具体延迟、带宽、丢包率与测速日期；
2. **`vendor`（商家官方宣称）**：来自商家官网文案或宣传物料（如“1小时修复承诺”、“晚高峰0卡顿”），在正文中统一添加“商家宣称/品牌资料显示”前缀；
3. **`pending`（待核实补充）**：当期套餐表或关键字段存在缺失，仅展示已有字段，严禁编造；
4. **`historical`（历史归档资料）**：采集于早期批次（如 2026 年 8 月以前），需等待当期最新官网截图比对后再更新。

## 四、后续核验与更新机制

1. **每月周期性巡检**：每月 1 号与 15 号通过自动化脚本检测全部推广链接的 HTTP 状态码，发现域名被阻断或异常跳转时立即告警；
2. **重大敏感期连通性抽检**：在敏感期抽测各品牌在晚高峰时段的丢包率，将异常状态实时同步至 [机场跑路预警雷达](/resources/run-warning/)；
3. **退款政策跟踪**：跟踪用户在各商家工单中的反馈，发现违规拒绝合理退款的商家调低信用评级。
