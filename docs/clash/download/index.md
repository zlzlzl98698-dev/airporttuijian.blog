## 五、密码学防伪校验实战：SHA-256 哈希散列值校验完整 SOP

SHA-256（安全散列算法 256 位）是目前全球信息安全领域应用最广泛的单向密码学生成函数。任何一个文件，哪怕其中仅有 1 个字节被黑客插入了恶意后门，其计算出来的 64 位十六进制哈希字符串就会发生彻底的雪崩式突变。

### 1. Windows 平台哈希校验保姆级 SOP
Windows 10 和 Windows 11 原生内置了强大的安全校验工具，完全无需额外下载第三方软件：

- **方法 A：使用系统自带命令行工具 CertUtil（极简高效）**：
  1. 按下快捷键 `Win + R`，输入 `cmd` 回车打开命令提示符。
  2. 输入以下命令（文件路径可直接将下载好的安装包拖入终端窗口自动补全）：
     ```cmd
     CertUtil -hashfile "C:\Users\用户名\Downloads\Clash.Verge_1.7.7_x64-setup.exe" SHA256
     ```
  3. 回车后，系统会在 1 秒内输出如下格式的哈希字符串：
     ```text
     SHA256 哈希(文件 C:\Users\...\Clash.Verge_1.7.7_x64-setup.exe):
     a3f78b9c20194e82b7d91e0a293847291a82749281a8c928471b82947192847a
     CertUtil: -hashfile 命令成功完成。
     ```

- **方法 B：使用 PowerShell 校验并自动判定匹配**：
  1. 打开 PowerShell 终端，执行：
     ```powershell
     Get-FileHash -Path "C:\Users\用户名\Downloads\Clash.Verge_1.7.7_x64-setup.exe" -Algorithm SHA256
     ```
  2. 若要让系统自动帮您肉眼对比，直接执行比对逻辑：
     ```powershell
     $OfficialHash = "官方Release页面给出的64位散列值"
     (Get-FileHash "Clash.Verge_1.7.7_x64-setup.exe" -Algorithm SHA256).Hash -eq $OfficialHash.ToUpper()
     ```
     如果输出结果为 **`True`**，代表文件 100% 绝对纯正安全；若输出 **`False`**，请立刻永久删除该文件！

### 2. macOS 苹果电脑平台校验 SOP
在 macOS 系统中，打开「终端（Terminal）」应用：
1. 输入以下指令（同样可将 `.dmg` 文件拖入终端）：

2. 终端会立即返回一串哈希字符串与文件名。
3. 打开 GitHub 官方 Release 页面对应的 `checksums.txt` 或发布说明，按键盘 `Command + F` 粘贴搜索该字符串。如果能精确搜到且对应文件名完全吻合，即可确认该包为开发者本人签名编译发布的正品。

### 3. Linux 平台校验 SOP
在 Linux 终端中执行系统标准的散列比对指令：
```bash
sha256sum clash-verge_1.7.7_amd64.deb
```
或者批量比对官方提供的校验文件：
```bash
sha256sum -c checksums.txt 2>&1 | grep "clash-verge"
```
如果输出显示 `OK`，代表文件完整且完全未被第三方篡改。

### 4. 极客与企业级进阶防御：GPG 密码学公钥签名核验指南
对于对网络资产安全有极致苛刻要求的金融行业人员、区块链投资机构以及出海企业核心技术人员，仅校验 SHA-256 哈希值仍然可能面临一种理论上的极端攻击场景：如果官方开发者的 GitHub 账号被高级黑客通过社会工程学窃取，黑客同时上传了带毒二进制包并更新了 `checksums.txt`，单纯比对散列值依然会被蒙蔽。

为了防御这种“供应链投毒（Supply Chain Attack）”，核心开源项目往往还会提供基于非对称加密体系的 **PGP / GPG 数字签名（.asc 或 .sig 文件）**：
1. **获取官方发布者的 GPG 签名公钥**：
   官方核心维护者通常会在其公开的 GitHub 个人主页（带有官方认证标记的 Keybase / GPG Key ID）公布其公钥指纹（Fingerprint）。
2. **本地导入公钥指纹**：
   在终端中执行指令导入开发者公钥：
   ```bash
   gpg --keyserver keyserver.ubuntu.com --recv-keys <开发者公钥ID>
   ```
3. **验证安装包的数字签名**：
   下载安装包同目录下的 `.sig` 签名文件，执行签名校验指令：
   ```bash
   gpg --verify Clash.Verge_1.7.7_x64-setup.exe.sig Clash.Verge_1.7.7_x64-setup.exe
   ```
4. **校验结论判定**：
   如果控制台明确输出 `Good signature from "Maintainer Name <email>"`，则在数学和密码学意义上百分之百证明：**该二进制程序必须由开发者本人的物理离线私钥签名签署，全球没有任何黑客或中间人能够在缺乏私钥的情况下伪造该签名**！

  2. **切勿点击右下角的“不运行”**；
  3. 细心观察会发现提示文字下方有一行可点击的浅色文字：「**更多信息（More info）**」，鼠标点击它；
  4. 此时对话框右下方会多出一个全新的按钮：「**仍要运行（Run anyway）**」；
  5. 点击该按钮，即可安全启动官方原版安装程序。

### 2. macOS Gatekeeper 拦截与“文件已损坏”终极解决
苹果 macOS 系统的防护机制更为严密。针对常见两种提示，执行针对性方案：
- **场景一：提示“无法打开，因为 Apple 无法检查其是否包含恶意软件”**：

  2. 点击屏幕左上角苹果图标 -> 打开「**系统设置**」；
  3. 在左侧菜单点击「**隐私与安全性**」，向下滑动至最底部的「安全性」分区；
  4. 您会清晰看到一行提示：“已阻止使用 Clash Verge，因为来自身份不明的开发者”；
  5. 点击旁边的「**仍要打开**」按钮，在弹窗中输入您的 Mac 开机锁屏密码或通过触控 ID 确认，即可顺利打开。
- **场景二：提示“App 已损坏，你应该将它移到废纸篓”**：
  - 这通常发生在部分高版本 macOS（如 Sonoma / Sequoia）上由于签名孤立导致的误判。
  - **一秒修复指令**：打开 Mac 终端，复制粘贴以下指令并回车（提示输入开机密码时盲打回车）：

在 Windows 下载列表中，通常并存着 `Setup` 安装包与 `Portable` 便携压缩包。深入理解两者的优劣，有助于在特定生产力场景下做出最明智的选择：

| **全盘卸载与痕迹清理** | 控制面板自带一键完整卸载向导 | 直接 Shift + Delete 删除整个文件夹即可 | 便携版具备零注册表残留优势，极其适合安全敏感人员 |

## 八、客户端长效维护：版本更新、数据备份与彻底卸载复位 SOP

安全下载不仅是一锤子买卖，在后续长期使用过程中的升级与维护同样关乎系统稳定性：

### 1. 安全升级的正确操作范式
- **永远不要在软件弹窗中盲目点击来源不明的外链升级**：很多带毒软件正是伪装成正版客户端的“强制升级弹窗”来二次感染系统的。
- **正规升级通道**：

  2. 或者每隔 1 至 2 个季度，主动访问官方 GitHub Releases 页面，查看是否有针对安全漏洞（如 OpenSSL、Go、Rust 核心库更新）修复的重要里程碑版本。
  3. 覆盖升级时，**完全无需提前卸载旧版本**！直接下载最新的 `setup.exe` 覆盖安装，您的所有订阅节点、自定义 Merge 规则与 JavaScript 扩展脚本将获得 100% 完整保留。

### 2. 彻底卸载与网络复位防瘫痪 SOP
如果未来更换设备或尝试其他工具需要卸载 Clash Verge Rev，请务必执行以下安全解绑流程，防止电脑陷入“无法上网”的断网死锁：
1. **第一步（关键）**：打开客户端，**手动关闭「系统代理」开关与「TUN 模式」开关**；

3. **第三步**：彻底退出托盘中的客户端图标；
4. **第四步**：打开 Windows 控制面板 -> 「程序和功能」，找到 Clash Verge 点击卸载；
5. **第五步**：若卸载后浏览器依然无法联网，进入系统「设置」 -> 「网络和 Internet」 -> 「代理」，确认「使用代理服务器」开关处于完全关闭状态即可瞬间复原。
