# Clash 节点全部超时或无法联网？10 大常见故障排查

使用 Clash 过程中，最令人沮丧的莫过于：**节点测速全部显示 Timeout（超时）、网页打不开，或者电脑关机重启后突然所有国内网页也无法联网**。

别慌，按照以下标准排查 SOP，99% 的常见问题可在 3 分钟内自行解决。

---

## 故障一：关机或意外退出后，电脑所有网页打不开？

- **原因**：Clash 在退出时未能正常清理 Windows 注册表中的“系统代理”设置，导致操作系统依然将请求发往 `127.0.0.1:7890`，但此时本地并没有代理程序监听。
- **快速修复**：
  1. 按 `Win + I` 打开 Windows 设置，搜索【代理】。
  2. 找到【手动设置代理】，将【使用代理服务器】的开关手动**关闭**。
  3. 或者直接重新启动 Clash Verge Rev，开启一次系统代理后再正常退出。

---

## 故障二：节点测速全部超时（Timeout），无法连接？

- **原因 1：系统时间存在偏差（最常见高频原因）**
  - VLESS 和 VMess 等现代加密协议要求客户端与服务器之间的时间差**不得超过 60 秒**。如果时间不同步，TLS 握手会直接失败。
  - **修复**：打开系统设置 ->【时间和语言】->【日期和时间】，点击【立即同步】。
- **原因 2：套餐流量用尽或订阅过期**
  - 登录机场后台核对账户剩余流量与到期时间。
- **原因 3：本地 7890 代理端口被冲突占用**
  - 打开 Clash Verge 设置，将 Mixed Port（混合端口）从 `7890` 修改为 `7895` 或其他未占用端口。

---

## 故障三：能看网页，但 Git、Telegram 或外服游戏无法连接？

- **原因**：某些终端命令工具或游戏不读取 Windows 系统的 HTTP 代理环境变量。
- **终极解决办法**：
  1. 打开 Clash Verge 设置中的【服务模式】，安装驱动。
  2. 开启【TUN 模式】。TUN 会在系统底层建立虚拟网卡，强制接管整机所有网络数据包。
