## 一、直接结论（Answer-First 通用四步极简连接闭环）

无论您手头使用的是哪一种操作系统，只要牢牢把握以下四大核心闭环步骤，即可在 3 分钟内实现稳定、高速、无感的科学上网：

1. **第一步：认准正规开源构建包，安装并切换中文**：
   - Windows 认准 `x64-setup.exe`；苹果 Mac 芯片认准 `aarch64.dmg`；安卓手机认准 `arm64-v8a.apk`。进入客户端界面第一件事，在「Settings」中切换为「简体中文」。
2. **第二步：在「订阅（Profiles）」面板直接导入标准订阅**：
   - 从老牌正规机场后台（如 [光速云](/reviews/guangsuyun)）复制原生标准 Clash YAML 订阅链接，粘贴至输入框点击「导入」，并将自动更新间隔配置为 `1440` 分钟（24 小时）。
3. **第三步：严格锁定「规则（Rule）」模式，严禁日常开启「全局」**：
   - 点击侧边栏「代理（Proxies）」，确认顶部主模式保持在「**规则（Rule）**」！在此模式下，国内微信、淘宝、网银 100% 走本地宽带直连，只有海外受限网站才会自动智能分流至最佳专线节点。
4. **第四步：开启代理开关，进阶用户首选「TUN 驱动模式」**：
   - 轻量网页浏览只需开启「系统代理」开关；若要让终端命令行、Git、Docker、外服网游全部享受硬件级透明加速，桌面端用户务必在「设置」中安装「服务模式」，随后开启「TUN 模式」，享受全盘无感出海。

## 二、四大操作系统端到端保姆级配置实战

针对不同操作系统的差异化特性，本站技术组整理了最详尽的实操指南：

```
                      【全平台 Clash 客户端部署工作流矩阵】
                                         │
    ┌──────────────────┬─────────────────┴────────────────┬──────────────────┐
    ▼                  ▼                                  ▼                  ▼
【Windows 平台】    【macOS 苹果平台】                  【Linux 开发者平台】  【Android 手机平台】
x64 安装版          aarch64 原生 DMG                    deb / rpm / AppImage  arm64-v8a APK 直装
解 SmartScreen 拦截 解 Gatekeeper 检疫隔离              赋予 +x 执行权限      解除手机电池优化限制
安装 Wintun 驱动    安装特权助手守护进程                配置 Systemd 服务     开启分应用代理模式
```

### 1. Windows 电脑平台（Windows 10 / 11 完全实操）
- **客户端首选**：**Clash Verge Rev**（基于 Tauri + Rust 架构，内存占用低至 50MB）。
- **完整操作流程**：
  1. **下载与解封运行**：从官方 GitHub 仓库下载 `Clash.Verge_*_x64-setup.exe`。运行若遇深蓝色「Windows 已保护你的电脑」提示框，点击「更多信息」 -> 点击「仍要运行」。
  2. **语言切换**：启动软件后，点击左侧菜单栏倒数第二项齿轮图标「Settings」，在「Language」下拉列表中选择「简体中文」。
  3. **导入订阅**：点击左侧「订阅」 -> 在顶部 URL 输入框中粘贴机场后台复制的标准 Clash 订阅链接 -> 点击右侧「导入」 -> 导入成功后右键卡片选择「编辑」，将「更新间隔」改为 `1440`。
  4. **节点选择**：点击左侧「代理」 -> 保持顶部为「规则」模式 -> 在「🚀 节点选择」分组中，点击延迟最低的香港或日本专线节点（如光速云 IEPL 专线）。
  5. **终极加速（可选但强烈推荐）**：点击左侧「设置」 -> 找到「服务模式」点击安装（地球图标变为绿色） -> 打开下方的「TUN 模式」开关。此时终端 CMD、PowerShell、Git 下载与各类游戏将自动全盘享受极速硬件级代理！

### 2. macOS 苹果电脑平台（MacBook Air / Pro / Mac mini / iMac）
- **客户端首选**：**Clash Verge Rev**（原生支持 Apple Silicon M1/M2/M3/M4 芯片与 Intel 架构）。
- **完整操作流程**：
  1. **芯片架构对齐**：M 系列自研芯片下载包含 `aarch64.dmg` 的镜像；2020 年前老款 Intel 芯片下载 `x64.dmg`。
  2. **安装与安全放行**：
     - 双击打开 `.dmg` 镜像，将 Clash Verge 图标拖入右侧的 `Applications` 应用程序文件夹；
     - 首次双击打开若提示“无法打开，因为 Apple 无法检查其是否包含恶意软件”，点击「取消」；
     - 打开 Mac「系统设置」 -> 「隐私与安全性」 -> 滑动至底部，点击“已阻止使用 Clash Verge”右侧的「**仍要打开**」并输入锁屏密码。
     - 若提示文件已损坏，在终端执行：`sudo xattr -r -d com.apple.quarantine /Applications/Clash\ Verge.app`。
  3. **安装特权助手（Privileged Helper）**：
     - 在软件「设置」面板中，点击「安装特权助手」，在系统弹窗中输入一次 Mac 开机密码。完成此步后，客户端未来在开机静默接管网络时将不再反复弹窗索要管理员密码。
  4. **导入并开启代理**：同 Windows 步骤，在「订阅」中粘贴导入并开启「系统代理」或「TUN 模式」，顶部状态栏会出现简洁的托盘图标。

### 3. Linux 平台（Ubuntu / Debian / Arch / Fedora）
- **客户端首选**：**Clash Verge Rev** 或 **Mihomo 内核独立守护进程**。
- **完整操作流程（以 Ubuntu 桌面版为例）**：
  1. 从官方 GitHub Releases 下载最新的 `.deb` 安装包：
     ```bash
     sudo dpkg -i clash-verge_*_amd64.deb
     sudo apt-get install -f # 自动补齐缺失依赖库
     ```
  2. 在应用菜单中启动 Clash Verge，导入订阅并切换为规则模式。
  3. 若要在 Linux 终端中全局生效代理，开启「TUN 模式」并给予网络管理员能力：
     ```bash
     sudo setcap cap_net_admin,cap_net_bind_service=+ep /usr/bin/clash-verge
     ```
  4. 或者在 `~/.bashrc` 中注入轻量环境变量别名：
     ```bash
     alias setproxy="export http_proxy=http://127.0.0.1:7890 https_proxy=http://127.0.0.1:7890 all_proxy=socks5://127.0.0.1:7890"
     alias unsetproxy="unset http_proxy https_proxy all_proxy"
     ```

### 4. Android 安卓手机平台（华为、小米、三星、OPPO、vivo、荣耀）
- **客户端首选**：**Clash Meta for Android (CMFA)** 或 **FlClash**。
- **完整操作流程（以 CMFA 为例）**：
  1. **官方 APK 安装**：从官方 GitHub 下载 `..._arm64-v8a.apk` 安装包。国产手机安全卫士若提示风险，点击「解除管控」或「继续安装」。
  2. **导入配置**：打开 CMFA -> 点击「配置（Profiles）」 -> 点击右上角「新配置」 -> 选择「URL (从 URL 导入)」 -> 粘贴机场订阅地址 -> 自动更新间隔设为 `1440` -> 点击右上角软盘图标保存并勾选激活。
  3. **启动代理服务**：返回主界面，点击中间大卡片「点击启动」，系统会弹出标准的 Android VpnService 权限请求框，点击「允许 / 确定」。
  4. **至关重要的省电与后台保活设置（防睡死）**：
     - 进入手机「系统设置」 -> 「应用管理」 -> 找到 Clash 软件；
     - 开启「自启动」与「关联启动」权限；
     - 进入「电池 / 省电策略」，将其从默认的“智能限制”强行修改为「**无限制 / 不受省电优化**」；
     - 打开手机多任务后台界面，在 Clash 卡片上下拉并点击“小锁”图标锁定常驻后台，彻底避免锁屏后被系统杀后台断网。
  5. **分应用代理配置（可选）**：在软件设置中开启「分应用代理」，勾选仅需要翻墙的海外软件（如 Twitter、Telegram、YouTube），让微信和支付宝彻底绕过代理客户端，达到极致省电效果。

### 5. iOS 苹果手机与 iPad 平台（Shadowrocket 小火箭保姆级实战）
虽然 iOS 系统无法直接运行基于 Tauri 的 Clash Verge，但苹果生态拥有体验极其出色的规则代理王者 **Shadowrocket（小火箭）**：
- **第一步：获取海外 Apple ID 并下载**：
  - 打开 App Store，退出国内 Apple ID，登录一个免税州美区或港区 Apple ID；
  - 搜索「Shadowrocket」（认准图标为浅蓝色背景、白色发射火箭，开发者为 Shadow Launch Technology）；
  - 下载安装完成后，退回美区账号，切回您个人的国内常用 Apple ID（已下载应用永久保留）。
- **第二步：订阅一键拉取**：
  - 在机场控制台（如 [光速云](/reviews/guangsuyun)）复制专用的「Shadowrocket 订阅」；
  - 打开小火箭，点击右上角「+」号，在第一行「类型」下拉菜单中选择「Subscribe」；
  - 在「URL」行粘贴订阅链接，在「备注」行填写机场名称，点击右上角「完成」；
  - 软件会自动在 1 秒内将数十个专线节点下载并渲染至首页列表。
- **第三步：路由策略与全局路由选择**：
  - 在小火箭首页正中央，找到「全局路由」行；
  - 确保将其切换为「**配置（Config）**」模式（切勿选全局代理）；
  - 点击底部的「配置」菜单，点击默认的 `default.conf`，可一键更新官方最新的国内白名单分流规则。
- **第四步：连接与系统 VPN 权限授权**：
  - 点击最顶部的连接开关，系统会弹窗提示“Shadowrocket 想要添加 VPN 配置”；
  - 点击「允许」，在弹出的锁屏密码界面输入 iPhone 数字密码或双击电源键完成面容 ID 验证；
  - 状态栏出现「VPN」小方框，打开 Safari 即可瞬间秒开全球网页！

### 6. 软路由平台（OpenWrt / iStoreOS / 旁路由透明代理部署实战）
对于拥有多台智能设备、外贸团队工作室或对全屋智能家居有加速需求的用户，在软路由上部署透明代理能够彻底摆脱终端安装软件的束缚：
- **插件首选**：**OpenClash** 或 **HomeProxy（Mihomo 原生驱动）**。
- **核心部署五步法**：
  1. 在软路由管理后台进入「服务」 -> 打开「OpenClash」；
  2. 进入「配置订阅」面板，在最下方输入机场的标准 Clash 订阅链接，勾选「在线订阅转换」，点击「保存配置并拉取」；
  3. 在「全局设置」中，将「运行模式」选择为「**Fake-IP (TUN 混合模式)**」；
  4. 将「内核版本」切换至最新的「Mihomo 内核」，享受次世代多线程极速转发；
  5. 点击「启动 OpenClash」，等待控制台日志显示主核心启动成功。此时全家连上该路由器 Wi-Fi 的所有设备（含电视、Switch、手机、扫地机器人），均可在零配置状态下全自动享受透明加速与智能分流！

## 三、三大核心路由模式底层机制与严谨选型对比

<div class="table-wrapper">

| 运行模式名称 | 核心路由流转逻辑 | 数据包处理路径 | 适用业务场景与核心优势 | 潜在弊端与高危风险 | 日常推荐指数 |

| **规则模式 (Rule)** | **微秒级黑白名单智能匹配** | 国内网站走 DIRECT，海外走节点 | **全天候 24 小时默认使用**，国内外完全无感 | 规则库过旧时偶有个别小站漏判 | ⭐⭐⭐⭐⭐ (绝对核心) |

## 五、生产力级长效运维：开机自启、快捷键盲操与自动更新最佳实践

为了让代理工具真正达到“润物细无声、日常完全感觉不到其存在”的境界，请花 2 分钟完成以下生产力调优：

### 1. 极致静默的开机无感自启配置
- 在 Clash Verge Rev 的「设置」面板中：
  - 打开「**开机自启（Auto Start）**」开关；
  - 打开「**静默启动（Silent Start）**」开关；
  - 将「**关闭窗口行为**」设置为「**最小化到托盘**」。

## 六、全平台通用的十大突发断网自愈排障 SOP

遇到突发断网时，请严格按照以下标准化 SOP 依序排查，99% 的问题均可在 1 分钟内自愈：

### 排障 1：关闭或卸载客户端后，全电脑网页彻底瘫痪打不开
- **故障根因**：系统代理注册表钩子残留，Windows 依然在向不存在的 7890 端口转发请求。
- **30 秒自愈**：按 `Win + i` 打开系统设置 -> 点击「网络和 Internet」 -> 「代理」 -> 在手动设置代理下方，手动将「**使用代理服务器**」拨至「**关**」并点击保存，物理网络瞬间满血复活。

### 排障 2：所有节点在测速时全线报红超时（Timeout）
- **故障根因**：本地电脑系统的绝对时钟与标准时间偏离超过 30 秒，导致 TLS 握手时间戳校验被服务端强行阻断。
- **30 秒自愈**：右键点击任务栏时间 -> 「调整日期和时间」 -> 点击「**立即同步**」按钮校准时钟，再次测速瞬间全绿。

### 排障 3：微信或 QQ 能正常收发文字，但浏览器打不开任何国内外网页
- **故障根因**：本地 DNS 模块发生死锁，或者 Fake-IP 缓存映射池溢出。
- **30 秒自愈**：打开命令提示符（CMD），输入 `ipconfig /flushdns` 刷空系统 DNS 缓存；在客户端「连接」面板点击「关闭所有连接」，重启一次内核即可。

### 排障 4：浏览器能顺利访问 Google，但在 CMD 终端或 Git 执行命令依然被墙
- **故障根因**：普通「系统代理」只接管遵循系统注册表的浏览器，命令行完全绕过代理直接走裸直连。
- **30 秒自愈**：在 Clash Verge Rev 中点击安装「服务模式」，随后开启「**TUN 模式**」，利用底层 Wintun 驱动将整台设备的所有底层数据包强制无感接管。

### 排障 5：苹果 Mac 电脑在切换 Wi-Fi 或从睡眠唤醒后，突然无法上网
- **故障根因**：物理网卡变更导致虚拟网卡的默认路由跃点数（Metric）发生竞争错乱。
- **30 秒自愈**：在 Mac 顶部托盘右键点击 Clash 图标，点击「重启内核（Restart Core）」，核心会在 1 秒内自动对齐全新的物理网关。

### 排障 6：开启代理后，访问国内淘宝、B站或网银极度缓慢或频繁跳验证码
- **故障根因**：客户端主模式误选为了「全局（Global）」，导致所有国内数据包绕道海外节点再折返回来。
- **30 秒自愈**：立即在「代理」面板顶部切换回「**规则（Rule）**」模式。

### 排障 7：订阅卡片右上角提示更新失败，报错“Invalid Format”
- **故障根因**：机场服务端正在遭受 DDoS 攻击返回了 Cloudflare 盾牌页面 HTML，或者误复制了单节点链接而非标准 Clash 订阅。
- **30 秒自愈**：确认机场后台复制的是「Clash 专用订阅」；勾选「使用代理更新」后重试一次。

### 排障 8：安卓手机锁屏待机 10 分钟后，打开手机发现断连无法接收海外消息
- **故障根因**：国产手机系统的激进电池管理机制在锁屏后自动杀死了后台代理进程。
- **30 秒自愈**：在系统设置中为客户端关闭“电池优化”，开启“允许自启动”并在多任务卡片上加锁常驻。

### 排障 9：打开软件报错“Port 7890 in use，启动内核失败”
- **故障根因**：上次关闭软件时残留了僵死进程，霸占了混合端口。
- **30 秒自愈**：按 `Ctrl + Shift + Esc` 打开任务管理器，强行结束名为 `clash-verge.exe` 或 `mihomo.exe` 的残留进程；或在设置中将混合端口改为 `7897` 保存。

### 排障 10：开启 TUN 模式后，局域网内的群晖 NAS 或家庭打印机搜不到了
- **故障根因**：TUN 虚拟网卡误将私有网段多播广播包抓走。
- **30 秒自愈**：在 DNS 高级设置的 `fake-ip-filter` 清单中添加 `*.lan` 与 `*.local`，并确保包含 `192.168.0.0/16,DIRECT` 直连规则。

### 排障 11：在 Windows 上玩局域网联机游戏（如《我的世界》、局域网对战）搜不到好友房间
- **故障根因**：开启了全局或 TUN 模式时，局域网广播数据包（255.255.255.255 / UDP 广播帧）被虚拟网卡拦截。
- **30 秒自愈**：在规则配置的最顶部，强制添加局域网广播网段直连：
  ```yaml
  prepend-rules:
    - IP-CIDR,255.255.255.255/32,DIRECT,no-resolve
    - IP-CIDR,224.0.0.0/4,DIRECT,no-resolve
  ```
  好友房间即刻秒级在联机大厅重新刷新出来。

### 排障 12：在 macOS 上开启代理后，AirDrop 隔空投送或隔空播放（AirPlay）频繁失败
- **故障根因**：苹果的 AWDL（Apple Wireless Direct Link）专用点对点协议依赖 mDNS 多播服务。
- **30 秒自愈**：在 Clash Verge Rev 的 Fake-IP 过滤名单中，加入苹果局域网发现特征域名：
  ```yaml
  fake-ip-filter:
    - '*.apple.com'
    - '*.local'
    - '*.icloud.com'
  ```
  隔空投送秒级恢复秒搜秒传。

### 排障 13：安卓手机开启代理后，运营商掌上营业厅 App 无法通过“一键免密登录”
- **故障根因**：运营商免密登录依赖手机基站对蜂窝网络数据包 HTTP 头的私有取号网关鉴权，代理流量导致网关无法识别底层真实 IMSI 号卡。
- **30 秒自愈**：在 CMFA 设置的「分应用代理」中，将移动/电信/联通营业厅勾选排除在代理之外，强制走真实蜂窝直连即可一秒完成免密取号。
