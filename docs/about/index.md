# 关于我们：网络监测实验室与独立技术评测使命

欢迎访问 **{{ $frontmatter.title || '机场推荐技术知识库' }}**。我们是由一群资深分布式网络工程师、网络安全研究员、外贸出海技术顾问共同发起并长期维护的独立网络技术监测团队。

在信息高度不对称、跑路盘与虚假黑产广告泛滥的跨境网络服务市场中，我们致力于通过**自动化探针监控、真实物理宽带压测、协议与拓扑逆向分析**，为科研人员、外贸跨境从业者及广大网络技术爱好者提供最客观、透明、可验证的技术指南与服务商评估数据。

---

## 我们的创立初衷与愿景

长期以来，中文互联网在科学上网、跨境访问与出海代理领域存在着严重的信息扭曲：

1. **虚假测速与跑路圈钱横行**：许多缺乏技术背景的用户被各大社交平台上“1元/月”、“9.9元永久包年”等虚假低价噱头吸引，最终因商家超售严重、断流跑路而蒙受资金损失与业务中断。
2. **黑公关与付费刷榜泛滥**：许多所谓“评测导航站”实质上由劣质机场主操盘，谁给的佣金高就将谁排在第一名，真实测速数据被随意篡改或人工伪造。
3. **技术普及滞后与断层严重**：普通用户面对复杂的代理内核（Mihomo/Clash/Sing-box）、路由分流规则、DNS 污染防范和指纹浏览器配置时往往无所适从，甚至因错误配置导致敏感数据外泄。

**我们的使命是：打破黑盒，让网络质量数据公开透明；普及技术，帮助每一位出海人员构建安全、稳定、合规的跨境网络防线。**

## 核心评测与编辑原则

为确保知识库中每一份评测、每一个排名、每一项推荐都具备坚实的证据支撑，我们自创立之初即确立了不可动摇的“四大铁律”：

### 1. 匿名自费与真实测试 (Anonymous Self-Funding)
实验室对所有收录与评测的服务商均通过公开渠道匿名注册、自费充值购买套餐，坚决拒绝接收任何服务商赠送的“特供专用节点”、“VIP 高优先级专线”或“管理层免审特权”。我们所测试到的每一条节点质量，与任何普通付费用户所获得的完全一致。

### 2. 拒绝付费修改评测结论 (Zero Editorial Interference)
商业合作绝对不得干预编辑独立性。无论任何品牌方是否与本站存在合规推广合作，若其在晚高峰发生严重丢包、被监测到恶意倍率偷跑、或出现跑路征兆，我们将第一时间在[跑路预警雷达](/resources/run-warning/)中发布风险通报，绝不隐瞒或删帖。

### 3. 数据驱动与长效监控 (Data-Driven & Continuous Monitoring)
我们坚信瞬间单次测速截图没有任何统计学价值。本实验室在全国主要骨干节点部署了 7×24 小时自动化探测探针，核心指标（丢包率、首包延迟、晚高峰吞吐、流媒体解锁能力）均基于连续数周甚至数月的长周期采样，详见[评测基准与方法论](/methodology/)。

### 4. 坚持以安全合规为底线 (Security & Compliance First)
本站所有内容严格恪守计算机网络科学研究与学术探讨边界。我们倡导正规外贸跨境办公、国际学术文献检索及开源软件合规开发，坚决反对并抵制任何利用代理技术从事违法犯罪、黑客攻击或侵犯他人合法权益的行为。

## 实验室成员与专业背景

本站研究人员平均拥有 8 年以上计算机网络与信息安全从业背景：

- **网络架构专家（Team Lead）**：曾任职于国内大型跨国企业与 IDC 运营商，专注于 BGP 骨干网路由优化、SD-WAN 与跨国专线（IEPL/IPLC）性能工程。
- **信息安全分析师**：专注于网络加密协议逆向、网络指纹对抗、恶意代码检测及跨境通信隐私泄露防范。
- **开源客户端维护者与极客**：活跃于 GitHub 代理生态社区，深入研究 Clash Meta (Mihomo)、Sing-box、Xray 等核心代码实现与规则集编写。
