# 隐私政策与零数据留存承诺 (Privacy Policy)

生效日期：2026年1月1日  
最后更新：2026年首季

**机场推荐技术团队**（以下简称“我们”或“本站”）深知个人隐私与网络安全的重要性。作为专注于网络加密通信与安全测评的技术团队，我们坚定践行 **“数据最小化（Data Minimization）”** 与 **“零日志留存（Zero-Logging）”** 的核心隐私工程哲学。

本《隐私政策》详细阐明了您在访问和浏览本站（`airporttuijian.blog`）时，我们如何处理技术信息，以及我们为保护您的匿名性与隐私权益所采取的严格技术与制度保障。

---

## 一、核心原则：零个人数据收集 (Zero Personal Data Collection)

1. **无需账户与注册**：本站为完全开放型的技术文档与公共评测知识库。您无需注册个人账号、无需填写姓名、手机号码、真实身份证件或电子邮箱即可无限制阅读全站所有内容。
2. **无中心化用户数据库**：本站架构为纯静态站点（Static Site Generation, SSG），底层不设立任何存储用户敏感个人身份信息（PII）的中央数据库。
3. **无密码与支付凭据存储**：本站不直接销售任何网络套餐或提供付费充值入口，绝不接触或存储您的任何银行卡号、支付宝/微信支付账号或加密货币钱包私钥。

---

## 二、我们处理的技术日志信息

为了保证网络基础设施的可用性、防范针对本站服务器的 DDoS 恶意攻击和爬虫滥用，托管服务商的基础设施层在您访问时可能会自动处理最小范围的机器通信日志：

| 数据类型 | 处理目的 | 留存周期 | 是否关联个人身份 |
| :--- | :--- | :--- | :--- |
| **访问请求时间戳** | 统计基础流量趋势与带宽吞吐负载 | 最长 7 天（循环覆盖自动销毁） | 否（无任何账号关联） |
| **匿名化 IP 地址** | 用于防御 CC/DDoS 泛洪攻击与防火墙限流 | 最长 24 小时（内存缓存） | 否（严格执行脱敏与掩码处理） |
| **请求的 URL 路径** | 诊断站内死链与 404 错误页面 | 最长 7 天 | 否 |
| **User-Agent 报头** | 用于适配不同移动终端（iOS/Android/桌面）排版 | 即时渲染后立即释放 | 否 |

**我们郑重承诺：绝不出售、出租、转让或与任何第三方广告数据经纪商共享上述任何网络日志信息。**

---

## 三、Cookie 与本地存储 (Local Storage) 使用规范

本站极力限制 Cookie 的使用：

1. **基本运行所需**：本站仅使用必要的本地存储（Local Storage）来记录您的阅读偏好设置（例如：暗黑模式/明亮模式切换、侧边栏折叠状态、以及[31家品牌数据库](/brands/)中的临时筛选记忆）。这些数据完全保存在您的本地浏览器中，绝不会自动上传至我们的服务器。
2. **禁用第三方追踪 Cookie**：本站绝不嵌入任何跨站广告追踪追踪像素（如 Facebook Pixel、Google DoubleClick 等商用追踪脚本）。
3. **完全由用户自主掌控**：您可以随时通过浏览器的“清除浏览数据”功能清空本地存储，亦可在浏览器安全设置中彻底禁用所有 Cookie，这不会影响您对本站正文文章的正常浏览与阅读。

---

## 四、外部链接与第三方网站隐私隔离

1. **外部跳转警示**：本站文章中不可避免地会包含指向第三方服务商（如机场官网、开源客户端 GitHub 仓库、知名安全工具站点）的超链接。当您点击这些链接离开本站时，您将直接受该第三方站点的隐私政策与服务条款管辖。
2. **防关联保护建议**：我们强烈建议用户在访问任何第三方代理服务商官网时：
   - 使用独立、无个人身份信息的隐匿电子邮箱（如 ProtonMail、DuckDuckGo 邮箱转发）注册；
   - 避免在不同平台间复用相同密码；
   - 详阅本站撰写的专题指南：[订阅链接保护与隐私安全防线](/resources/risk-intel/subscription-security)。

---

## 五、儿童与未成年人隐私保护

本站所提供的网络技术架构分析、开源代理配置及测速报告主要面向具备完全民事行为能力的计算机技术人员、学术研究者及外贸从业人员。我们不会在知情的情况下收集或处理任何 18 周岁以下未成年人的个人数据。

---

## 六、您的法定权利与隐私行使渠道

根据全球通行的隐私保护标准（包括中国《个人信息保护法》PIPL、欧盟通用数据保护条例 GDPR 及加利福尼亚消费者隐私法案 CCPA），您享有以下法定权利：

- **知情权**：了解您的数据如何被收集与使用的权利（本政策即为行使知情权之途径）；
- **删除与清空权**：由于本站并不收集或留存您的个人信息，若您对某些技术测试日志有顾虑，可通过清理本地浏览器数据即时完成个人痕迹清除；
- **隐私问题垂询**：若您对本站的隐私保护措施有任何技术疑问或发现任何潜在的安全漏洞，请通过 [联系我们](/contact/) 与我们的安全工程师沟通。

---

## 七、隐私政策的修订

随着网络技术的进步与相关法律法规的更新，我们可能会适时修订本《隐私政策》。任何重大变更均会在本页面顶部更新“最后更新”日期，并以醒目形式予以标明。建议您定期查阅以获悉最新的隐私保护实践。
