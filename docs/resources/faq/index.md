### Q2：为什么我的节点在 Clash 里 Ping 延迟很低，但打开网页很慢？
**答**：Clash 节点列表里的“Ping”测试，大多数默认只是测试本地到节点入口服务器之间的 **TCP/ICMP 握手延迟**，它只能代表国内连接顺畅，并不代表该节点到目标网站的真实下行吞吐带宽。真实速度必须以 Speedtest 或 YouTube 4K 实测为准。

---

### Q3：为什么开启了代理后，查 IP 地址依然显示在国内？
**答**：这是因为 Clash 默认开启了【规则模式（Rule）】。国内查 IP 的网站（如 ip138、百度）属于国内域名，被规则自动分流到了 DIRECT（直连），因此展示的是你的真实宽带 IP。如果打开海外的 `ipinfo.io`，就会正确显示为机场海外节点的 IP。

---

### Q4：机场套餐里的“流量倍率”是什么意思？
**答**：倍率代表该节点消耗流量的计费系数：
- 1.0x 倍率：实际消耗 1GB，扣除套餐 1GB；
- 0.5x 倍率：实际消耗 1GB，仅扣除套餐 0.5GB（通常用于冷门备用节点）；
- 2.0x / 3.0x 倍率：实际消耗 1GB，扣除 2GB 或 3GB（通常用于昂贵的高速专线节点）。
- [光速云](/reviews/guangsuyun) 与 [无忧链接](/reviews/wuyou) 主打全节点 1 倍率，无隐藏扣费。

### Q5：手机上开启了代理，为什么极其耗电？
**答**：请检查是否误开了 Global 全局模式。开启全局模式后，微信后台、推送服务等海量国内心跳包不断走代理转发，会极大增加芯片解密功耗。务必保持为 Rule 规则分流模式。
