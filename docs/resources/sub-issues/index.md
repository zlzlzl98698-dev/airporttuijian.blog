# 机场订阅链接更新失败排错指南

当你在 Clash 或小火箭中点击【更新订阅】时，突然弹出 `Subscription failed`、`404 Not Found` 或 `Network Error`，往往意味着客户端与机场配置服务器失去了连接。

按照以下三步排查法，快速定位并恢复订阅。

---
