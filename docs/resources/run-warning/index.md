# 机场跑路预警雷达与防坑手册

“机场又跑路了”是中文翻墙圈内屡见不鲜的悲剧。所谓“跑路”，指服务商在收取大量用户的季度付、年付资金后，突然关闭服务器、解散 Telegram 群组或拉黑用户，彻底失联。

本文整理跑路商家的常见演化套路，并提供风险识别雷达。

---

## 跑路商家的三大典型剧本

### 剧本一：低价走量收割盘（开业 1–3 个月）
商家用极低的成本租用廉价单线服务器，打出“9.9 包年 1TB”或“29 元买永久无限”等极其夸张的广告。在各大论坛批量推流，吸引上万名小白付款后，直接卷款关服跑路。

### 剧本二：击鼓传花甩盘盘（开业 1–2 年）
机场运维成本（专线租金、带宽费）超过营收，商家入不敷出。商家不肯自掏腰包补贴，便在跑路前两周开展“周年庆 5 折充值返现活动”，等最后一波大额充值到账后，立即关站失联。

### 剧本三：技术停滞被封锁盘
并非恶意卷款，但由于技术团队水平极低，在敏感期遇到 GFW 封锁入口后完全没有应急能力，无法修复，最终被迫摆烂弃坑。

---

## 跑路前期的危险信号（红色预警）

- ⚠️ 官网工单超过 72 小时无人应答；
- ⚠️ 官方 TG 交流群突然开启全员禁言，只保留公告频道；
- ⚠️ 频繁开展 3 折、4 折等远低于硬件成本的“充值大促”；
- ⚠️ 节点连续数日大面积报红且官方没有任何检修进度公告。
